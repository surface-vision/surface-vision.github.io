The other console

The Python console, in full, in this repository.

The detector on the front page runs in your browser and needs no server. This is the other half: a Streamlit console that does the things a tab should not be asked to do — batch scoring and coil reports, EigenCAM attention maps, a line-speed simulation, and the out-of-scope gate that runs before the detector. It is not a plan and not a screenshot. Every file it needs is below.

Hugging Face moved Docker and Gradio Spaces on free CPU behind a PRO subscription and left only static Spaces free, so this container has no free host there. That is a price list, not a defect: the package is an ordinary Docker image and runs anywhere a container runs, starting with your laptop. 

git clone https://github.com/surface-vision/surface-vision.github.io.git
cd surface-vision.github.io/console
docker build -t surface-console . && docker run -p 7860:7860 surface-console

Then open http://127.0.0.1:7860. Without Docker, pip install -r requirements.txt && streamlit run app.py on Python 3.11 does the same. Both checkpoints are in the clone, so there is nothing to download and no token to obtain.

To host it rather than run it, the same directory is mirrored at surface-vision/surface-vision-console, laid out at the repository root the way Streamlit Community Cloud expects to find app.py, requirements.txt and packages.txt. DEPLOY.md is the click-by-click. Nothing is deployed there yet -- the repository is the deployable artefact, not a running service.

Every file

Plus 18 NEU-DET sample frames under data/neu-det/test/images/ and one line-scan strip capture under assets/, so the batch and simulation tabs have something to run on out of the box.
