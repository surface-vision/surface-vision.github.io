Audit trail

Every number, and the file it came from.

The site states figures and names its sources inline. This is where those sources actually are: 14 report narratives, 28 JSON artefacts, the deck, the parity harness output, and the full source of the Python console. Nothing here is a summary written for the page — these are the files the experiments wrote.

One transformation was applied on copy, and only one: absolute build paths of the form /Users/…/JSW-PS1/ were rewritten to repository-relative, because a file served publicly should not publish the build host's home directory. No number, table or sentence was changed. The originals live in the project's reports/ and deck/.

Report narratives

Each one is the write-up of an experiment, including the ones that did not go the way they were supposed to. Markdown renders as plain text in the browser; GitHub renders it formatted.

Evaluation report
evaluation.md
 The shipped model on the held-out test split: mAP50 0.7524, mAP50-95 0.3967, precision 0.696, recall 0.687, and 98.9% classification accuracy (178 of 180 frames). 10 KB
Model selection study
model_study.md
 YOLOv8n against YOLOv8s on NEU-DET. Nano wins by +0.0688 mAP50 at training size, 95% CI [+0.0309, +0.0990], in 99.95% of 2,000 bootstrap resamples -- with 3.012 M parameters against 11.138 M. 48 KB
Resolution study
resolution_study.md
 128 px to 640 px, inference and training. The 640 px arm scores 0.7338, inside the +/-0.0254 noise band, at roughly 65 s per epoch. 30 KB
Input pipeline: the decision
input_pipeline_decision.md
 Why the frame is scaled rather than letterboxed. Lossless padding loses 0.024-0.052 mAP50 to ordinary bilinear scaling on 8 of 8 configurations. 26 KB
Input pipeline: the study
input_study.md
 The five-arm experiment behind that decision -- preserve the pixels, or interpolate them. 22 KB

calibration.md
 Isotonic regression fitted on val. Expected calibration error 0.142 -> 0.046 with mAP unchanged, which is what makes the probability this page prints a probability. 8 KB
Cross-domain fix
gap1_cross_domain_fix.md
 The joint checkpoint: clean-frame false alarms 93.7% -> 32.5%, cross-domain ROC AUC 0.608 -> 0.958, Severstal defect recall 72.0% -> 86.6%, mAP50 0.7642. 39 KB

false_alarm.md
 The false alarm rate on defect-free frames and the operating point it implies. conf 0.15 is set by a 90% detection floor, not by the cost model. 19 KB

 Photometric normalisation and the OOD gate: 0 false rejections across 3,200 genuine steel frames. This gate is in the Python console, not in this page. 22 KB

GC10 dataset and edge defects

 Roll-mark and edge-defect coverage, and exactly how far it goes. Edge cracks have no public dataset; the geometric proxy (crescent_gap + waist_fold) reaches AP50 0.880. 16 KB

Verification and console source

Parity harness output

parity_report.json is the browser decode path against Python ultralytics under onnxruntime-node; parity_browser.json is the published page itself driven in headless Chrome; strip_check.json is the wide-strip comparison, squashed against tiled. The harness that writes them is verify/.

Python console

The Streamlit console in full at console/ — the app, the six vendor/ modules, the Dockerfile, the CPU-pinned requirements, the sample frames and both checkpoints. Browse it on GitHub.

Detector source

The three modules that produce every box on the live page: detect.js, tiling.js and calibration.js. The same files the harness imports.
